ROBERT PORTFOLIO — HOMEPAGE STARTER
==================================

FILES
- index.html      Homepage structure and startup sequence
- style.css       All layout, colors, responsive design and animations
- script.js       Intro timeline, falling-code effect, typing animation and menu
- profile.png     Put YOUR portrait image here (same folder as index.html)
- assets/favicon.svg

HOW TO RUN
1. Extract the ZIP folder.
2. Put your own photo in the folder beside index.html and name it exactly: profile.png
3. Double-click index.html to preview, or use VS Code + Live Server.
4. Internet is only needed for the Google Fonts link. The animation and page design run locally.

CUSTOMIZATION
- Edit role phrases in script.js inside the `roles` array.
- Edit intro timings near `setTimeout(showStage...)` in script.js.
- Edit colors at the top of style.css in the `:root` block.
- Replace profile.png with your own image. The sample portrait is intentionally not included.
